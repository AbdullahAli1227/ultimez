# ULTIMEZ Phase 1 + Phase 2

This package combines the Phase 1 productivity dashboard with the Phase 2 requirements shown in the assignment:

## Phase 1 retained
- Registration and login
- Dashboard overview
- Task creation, editing, completion and deletion
- Task priorities and categories
- Schedule/calendar view
- User profile
- Responsive mobile layout
- Local browser data storage

## Phase 2 added
- Drag-and-drop Task Board: To Do / In Progress / Done
- Task reminders
- Browser notification support
- Personal note-taking with create/edit/delete
- Calendar navigation
- Google Calendar event links
- `.ics` calendar export for Google Calendar, Outlook and Apple Calendar
- Reminder/calendar controls in the dashboard

## Run
Open `index.html` directly in a modern browser, or use VS Code Live Server.

No backend or external package installation is required.

## Important
The authentication and data storage are demo/local-browser functionality using `localStorage`; this is suitable for a front-end internship phase submission, not production security.
